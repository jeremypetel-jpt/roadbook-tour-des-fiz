# Roadbook Tour des Fiz

Roadbook interactif pour un trek en bivouac du 20 au 22 aout 2026.

## Fonctions

- Traces et profils altimetriques des trois etapes
- Fonds Plan IGN, photographie aerienne et carte de randonnee
- Points d'eau, bivouacs et panoramas
- Itineraire secondaire GPX pour la troisieme etape
- Position GPS en direct
- Consultation hors ligne apres une premiere ouverture

Site publie avec GitHub Pages.
